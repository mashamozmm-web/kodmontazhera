# КОД МОНТАЖЁРА — Практикум 2027

Мобильный лендинг (HTML / CSS / JS + `send.php` для приёма заявок в Telegram).

## Структура файлов

- `index.html` — разметка всех 5 экранов + модальная форма «Занять место»
- `styles.css` — адаптивные стили (320px–430px + центровка на десктопе, эффект glass)
- `script.js` — слайдер аудитории, табы «THE CREATOR» с видеоплеером, модули программы и валидация/отправка формы
- `config.js` — **главный файл настроек** (ссылки на соцсети, документы оферты/согласий и пути к видео)
- `send.php` — серверный обработчик формы, который отправляет заявки напрямую в Telegram (`@montagecore`)
- `assets/` — вся графика и стикеры (Retina PNG)
- `videos/` — папка для 3 вертикальных видео (MP4, 9:16)

## 1. Как подключить отправку заявок в Telegram (`@montagecore`)

Сайт не может писать в Telegram без бота (это правило самого Telegram). Настройка занимает 2 минуты:

1. Откройте в Telegram бота **@BotFather**, нажмите `/newbot`, придумайте имя и username бота (например, `KodMontazheraLeadsBot`). Скопируйте выданный **токен**.
2. Откройте созданного бота с аккаунта **@montagecore** и нажмите **Start** (либо добавьте бота администратором в отдельный приватный чат/канал для заявок и напишите туда любое сообщение).
3. Откройте в браузере ссылку (подставив свой токен):
   `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`
   Найдите число в `"chat":{"id": 123456789}` — это ваш **Chat ID**.
4. Откройте файл `send.php` и вставьте полученные значения в строки:
   - `$BOT_TOKEN = '...';`
   - `$CHAT_ID = '...';`

После загрузки на PHP-хостинг (Timeweb, Beget, REG.RU) каждая заявка будет мгновенно приходить в Telegram со всеми полями (имя, `@ник`, телефон, выбранный вариант оплаты и статусы обеих галочек).

## 2. Как прописать ссылки на документы и соцсети

Откройте файл `config.js` и укажите реальные ссылки:
- `telegram` — уже прописан `https://t.me/montagecore`
- `instagram` — ссылка на Instagram
- `offer` — ссылка на документ **«Публичная оферта»** (используется и в чекбоксе №1, и в подвале)
- `marketingConsent` — ссылка на документ **«Согласие, цель – рекламная рассылка»** (используется в чекбоксе №2)
- `privacy` — ссылка на **«Согласие на обработку данных»** (в подвале)

## 3. Как добавить 3 видео в телефоны («THE CREATOR»)

Положите 3 вертикальных MP4-файла (H.264, 720×1280, до 3–8 МБ) в папку `videos/`:
- `videos/trends.mp4`
- `videos/creative.mp4`
- `videos/money.mp4`

## 4. Как выложить на хостинг (рекомендуется для РФ)

1. На **Timeweb / Beget / REG.RU** загрузите все файлы из папки `kod-montazhera` в `public_html` (или `www`).
2. Привяжите домен и включите бесплатный SSL-сертификат Let's Encrypt (`https://`).
3. Откройте сайт на телефоне и отправьте тестовую заявку — она сразу прилетит в Telegram!
